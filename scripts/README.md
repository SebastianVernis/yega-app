# Scripts Directory

This directory contains various scripts organized by type:

## Directories

- `shell/` - Shell scripts for system operations, deployment, and management
- `test/` - JavaScript test scripts for various components

## Shell Scripts

- `build.sh` - Build the application for production
- `deploy.sh` - Deploy the application with various options
- `install-mongodb.sh` - Install MongoDB on the system
- `reload-caddy.sh` - Reload the Caddy web server configuration
- `restart-backend.sh` - Restart the backend service

## Test Scripts

- `test-backend.js` - Test the backend API
- `test-email.js` - Test email functionality
- `test-mongodb.js` - Test MongoDB connection
- `test-otp-email.js` - Test OTP email sending
- `test-otp-verify.js` - Test OTP verification
- `test-proxy.js` - Test proxy configuration

## Setup Scripts

- `setup-manda2-db.js` - Set up the Manda2 database with initial data

These scripts are organized to make it easier to find and use the right script for each task.
