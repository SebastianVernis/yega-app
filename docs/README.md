# Documentation Directory

This directory contains all project documentation organized by category:

## Directories

- `archive/` - Historical documentation and archived materials
- `root/` - Documentation files that were previously in the project root
- `scripts/` - Utility scripts for documentation and development

## Archive Documentation

The `archive/` directory contains historical documentation including:
- Project architecture and design documents
- Workflow and process documentation
- Status reports and checklists
- API documentation
- Testing guides
- Deployment guides

## Root Documentation

The `root/` directory contains documentation files that were previously in the project root:
- `CRUSH.md` - Project development guide
- `GEMINI.md` - Gemini-specific documentation
- `MONGODB_SETUP.md` - MongoDB setup guide
- `README.md` - Main project README
- `SERVER_SETUP.md` - Server setup guide

## Scripts

The `scripts/` directory contains utility scripts:
- Document creation scripts
- Test scripts for document review functionality
- Server reload scripts
